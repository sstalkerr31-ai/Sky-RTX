# 🌌 SkyRT — аппаратная трассировка лучей для *Sky: Children of the Light*

> **Статус:** 🛠️ экспериментальный, активно развивается. Только ПК · Vulkan · NVIDIA RTX (аппаратный `ray_query`).

SkyRT — это **неявный слой Vulkan**, который добавляет в *Sky: Children of the Light* настоящую аппаратную трассировку лучей **без изменения файлов игры**. Каждый кадр он собирает сцену в структуры ускорения, трассирует лучи по реальной геометрии и подмешивает результат в HDR-изображение игры до постобработки. В комплекте небольшая **панель управления** (установка в один клик, настройки на лету, запуск игры).

## ✨ Возможности

| Возможность | Состояние |

| Установщик в один клик и панель с настройками на лету | ✅ |

| Трава и листва в структуре лучей | ❌ пока нет |
| Свет от костров и светящихся объектов, несколько отскоков GI | ❌ пока нет |

## 🥇 Чем SkyRT отличается

На октябрь 2026 мы **не знаем других публичных проектов с аппаратной трассировкой лучей для Sky** (искали на GitHub, Nexus Mods и в сети). Всё, что есть сейчас, это пост-обработка:

| | ReShade / «RTGI»-пресеты | **SkyRT** |
|---|---|---|
| Лучи трассируются по | буферу глубины (экранное пространство) | **реальной геометрии сцены (BLAS/TLAS)** |
| Тень от того, что вне экрана или за стеной | ❌ | ✅ |
| Тени движущихся персонажей | ❌ | ✅ |
| Использует RTX-железо (`ray_query`) | ❌ | ✅ |
| Изменяет файлы игры | нет | нет |

NVIDIA RTX Remix не подходит: он рассчитан на игры DirectX 8/9 с фиксированным конвейером. Если знаешь другой проект с аппаратными лучами для Sky, открой issue.

## 🚀 Быстрый старт

**Требования:** Windows 10/11 · видеокарта NVIDIA RTX с актуальными драйверами (проверено только на RTX 5070 Ti; теоретически подойдёт любая карта с `VK_KHR_ray_query` и `VK_KHR_acceleration_structure`) · *Sky: Children of the Light* для ПК.

1. **Скачай** свежий `SkyRT-x.y.z.zip` на странице [Releases](../../releases) и распакуй куда угодно.
   *(Релиза ещё нет? Смотри [сборку из исходников](#️-сборка-из-исходников).)*
2. **Запусти `SkyRT_Panel.exe`** → вкладка **Игра** → нажми **Установить лучи**. Слой скопируется в `%LOCALAPPDATA%\SkyRT` и зарегистрируется для твоего пользователя Windows. Права администратора не нужны. После этого распакованную папку можно удалить.
3. **Укажи путь к `Sky.exe`** (кнопка *Обзор*) и нажми **▶ Играть с лучами**.

Готово. В игре нажми **Ctrl+Home**, чтобы сравнить картинку с лучами и без.

> Слой загружается только для процесса игры, запущенного кнопкой панели *Играть с лучами* (она ставит `SKYRT_ENABLE=1` для этого процесса). Другие Vulkan-программы не затрагиваются.
> Если игру нужно запускать через другой лаунчер (Steam, свой лаунчер), задай переменную окружения `SKYRT_ENABLE=1` для этого лаунчера.

**Удаление:** открой панель → **Удалить лучи**. Затем удали папку `%LOCALAPPDATA%\SkyRT`, если хочешь стереть и файлы.

## 🎛️ Панель управления

| Вкладка | Что делает |
|---|---|
| **Игра** | Статус файлов / слоя / пути к игре · *Установить* / *Удалить* · путь к `Sky.exe` · **Играть с лучами** · Играть без лучей · переключатель языка (RU/EN) |
| **Графика** | Пресеты (Низкий / Средний / Высокий / Ультра / Свой) и ползунки на каждую настройку. Любое изменение записывается в `SkyRT.cfg` и применяется **на лету**, пока игра запущена |
| **Лог** | Свежий `SkyRT_*.log` с автообновлением и кнопкой *Открыть папку*. Этот файл прикладывай к сообщениям об ошибках |

Пресеты: **Низкий** 1 луч теней / 2 луча AO, без GI · **Средний** 2 / 4 (по умолчанию) · **Высокий** 4 / 6, дальность GI 40 · **Ультра** 8 / 8, до 24 накопленных кадров, дальность GI 60.

## ⚙️ Справочник по настройкам

Всё, что меняет панель, лежит в `%LOCALAPPDATA%\SkyRT\SkyRT.cfg` (обычные строки `ключ=значение`, файл перечитывается примерно раз в секунду). Можно править руками.

| Ключ | Диапазон | Что значит |
|---|---|---|
| `enabled` | 0/1 | Лучи вкл/выкл (0 = оригинальная картинка) |
| `shadows` · `strength` · `sunsize` · `shrays` | 0/1 · 0–1 · 0–10° · 1–8 | Тени: вкл/выкл, тёмность, размер полутени, лучей на пиксель |
| `ao` · `aostrength` · `aoradius` · `aorays` | 0/1 · 0–1 · 0.05–20 · 1–8 | AO: вкл/выкл, сила, радиус (в единицах мира), лучей на пиксель |
| `gi` · `gistrength` · `girange` | 0/1 · 0–2 · 1–200 | Отражённый свет: вкл/выкл, сила, как далеко смотрят лучи |
| `taa` · `taan` | 0/1 · 1–64 | Накопление по кадрам: вкл/выкл, максимум кадров (меньше = меньше шлейфов, больше шума) |
| `dyngeo` | 0/1 | Персонажи и анимированные меши отбрасывают лучевые тени |
| `instgeo` | 0/1 | Мелкие инстансные объекты в структуре лучей (эксперимент) |
| `gimulti` | 0–0.9 | Многократные отскоки света: каждый кадр добавляет ещё один отскок (нужен `taa=1`); 0 = один отскок |
| `light` | 0/1 | Свет от огня, свечей и ламп: очень яркие пиксели кадра становятся источниками света, которые освещают и затеняют окружение (новое, требует проверки) |
| `lightstrength` · `lightrange` | 0–200 (по умолчанию 10) · 1–60 | Яркость света и дальность одного источника (в единицах мира) |
| `lightmax` | 0.05–5 | Мягкий потолок света, добавляемого в одну точку (меньше = без пересвета) |
| `lightthr` · `lightrays` · `lightdebug` | 0.3–50 · 1–4 · 0/1 | Порог яркости, с которого пиксель считается источником (лог пишет самый яркий пиксель), теневых лучей на пиксель, покрасить найденные источники розовым |
| `aniso` · `lodbias` | 0–16 · −2…1 | Анизотропная фильтрация, сдвиг резкости текстур (**применяется при следующем запуске игры**) |
| `autosun` · `az` · `el` | 0/1 · 0–360° · 1–89° | Брать солнце из игры или задать вручную |
| `view` | 0–7 | Режимы отладки (см. клавиши) |

Больше лучей = меньше шума, но больше работы для видеокарты. Sky обычно упирается в процессор, так что у GPU, как правило, большой запас.

## ⌨️ Горячие клавиши в игре

| Клавиши | Действие |
|---|---|
| **Ctrl+Home** | Лучи вкл/выкл (сравнение с оригиналом) |
| **Ctrl+End** | Следующий режим: 0 полная картинка · 1 только тени · 2 только AO · 3 только отражённый свет · 4 карта AO (отладка) · 5 карта света (отладка) · 6 сетка (отладка) · 7 нормали (отладка) |

Если картинка выглядит странно, жми **Ctrl+End**, пока не вернётся режим 0 (или поставь `view=0`).

## 🧯 Проблемы и вопросы

**Ничего не меняется / картинка как в оригинале.**
Проверь панель: *Слой Vulkan* должен быть «установлен», а игра запущена кнопкой **Играть с лучами**. Открой вкладку **Лог**: при старте игры должен появиться свежий `SkyRT_*.log`. Нет лога значит слой не загрузился (не тот лаунчер, не задан `SKYRT_ENABLE`).

**Игра не запускается из панели.** Панель запускает `Sky.exe` напрямую. Если твоей версии нужен Steam или другой лаунчер, запусти игру там с переменной окружения `SKYRT_ENABLE=1`.

**Странные цвета / чёрный мир.** Жми Ctrl+End до режима 0 или поставь `view=0`. Если не помогло, поставь `enabled=0` и пришли лог.

**Низкий FPS.** Выбери пресет *Низкий* или уменьши `shrays` / `aorays`. Для проверки отключи `instgeo` и `dyngeo`.

**Шлейфы за персонажами / при быстрой камере.** Уменьши `taan` (попробуй 6).

**Света от огня нет или светятся обычные поверхности.** Поставь `lightdebug=1`: пиксели, которые считаются источниками, станут розовыми. Если у костра ничего розового нет, уменьши `lightthr`; если розовая освещённая солнцем земля, увеличь. В `SkyRT_*.log` каждые несколько секунд пишется самый яркий пиксель (`rt: emissive lights: ...`).

**Тени прыгают при смене сцены.** Направление солнца сглаживается, при настоящей смене сцены переход занимает около секунды.

**Вылет или зависание.** Открой issue и приложи свежий `SkyRT_*.log` (вкладка Лог → *Открыть папку*). Если в конце лога нет строки «clean shutdown», значит, игра упала.

**Windows SmartScreen / антивирус ругается на `SkyRT_Panel.exe` / `SkyRT.dll`.** Файлы не подписаны, а DLL, которые перехватывают графические API, часто попадают под эвристику. Всё можно собрать самому из этого репозитория.

**Это безопасно для моего аккаунта?** Слой не трогает файлы и память игры и ничего никуда не отправляет, но это неофициальная модификация клиента онлайн-игры. Используй на свой риск.

**Работает на AMD / Intel?** Не проверено. Теоретически подойдёт любая карта с `VK_KHR_ray_query` и `VK_KHR_acceleration_structure`.

## 🛠️ Сборка из исходников

Нужно: Visual Studio (C++ x64) · [Vulkan SDK](https://vulkan.lunarg.com/) · Python 3.8+ (для панели).

```bat
:: открой "x64 Native Tools Command Prompt for VS", затем:
cd layer
build.bat                       :: -> SkyRT.dll
cd ..\panel
build_panel.bat                 :: -> dist\SkyRT_Panel.exe  (ставит PyQt5 и PyInstaller)
cd ..
powershell -ExecutionPolicy Bypass -File release\package_release.ps1 -Version 0.20.0   :: -> dist\SkyRT-0.20.0.zip
```

Запуск панели из исходников: `pip install PyQt5`, затем `python panel\skyrt_panel.py` (рядом должны лежать `SkyRT.dll` и `VK_LAYER_SKYRT.json`).
Ручная установка без панели: `layer\install.ps1` регистрирует слой (`-Uninstall` удаляет, `-Machine` из админской консоли пишет в HKLM).

После правки шейдера `.comp`: `glslangValidator -V --target-env vulkan1.2 layer\rt_fx.comp -o rtfx.spv`, затем `python tools\spv2h.py rtfx.spv layer\rtfx_spv.h kRtFxSpv rt_fx.comp` (шейдер трассировки это `rt.comp` → `rt_spv.h`, массив `kRtSpv`; шейдер поиска света это `rt_light.comp` → `rtlight_spv.h`, массив `kRtLightSpv`).

## 🧩 Как это работает

- Слой включает на устройстве игры `VK_KHR_acceleration_structure`, `VK_KHR_ray_query`, `VK_KHR_deferred_host_operations` и адреса буферов.
- Запоминаются отрисовки основного прохода (вершинные/индексные буферы, пайплайн, indirect-аргументы). Статическая геометрия кэшируется в кольце слотов BLAS; геометрия в буферах, которые пишет CPU (скелетные персонажи), и несколько инстансных объектов каждый кадр пересобираются в динамическую BLAS. Всё вместе попадает в один TLAS.
- После основного прохода запускаются три вычислительных прохода: `rt_light.comp` (находит яркие светящиеся пиксели и сливает их по плиткам экрана в список источников света), `rt.comp` (лучи теней, AO и отражённого света через `ray_query`) и `rt_fx.comp` (билатеральное размытие, накопление по кадрам, подмешивание в цветовое изображение).
- Слой опирается на такие факты об игре: обратная глубина (reverse-Z), ось y вверх, UBO кадра на 1584 байта (матрица вида-проекции, камера, направление света).

## 🚧 Планы и ограничения

- [x] Слой Vulkan, доступ к HDR и глубине, извлечение матриц
- [x] BLAS/TLAS, тени через `ray_query`, динамическая геометрия (персонажи)
- [x] AO + отражённый свет, шумоподавление, накопление по кадрам
- [x] Установщик в один клик и панель управления
- [ ] Найти и трассировать поверхность воды (отражения / преломления)
- [ ] Растительность в структуре лучей
- [ ] Несколько отскоков GI, свет от костров и светящихся объектов

Известные ограничения: статическая геометрия считается неподвижной; объекты, анимируемые на GPU (ветер, волны), не отражаются в тенях; у поверхностей попадания нет материала, поэтому отражённый свет берётся из того, что видно на экране.
